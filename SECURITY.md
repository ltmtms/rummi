# Security Policy

## Supported versions

Security fixes land on the default branch. This is a static, client-side game with no server and no accounts.

## Reporting a vulnerability

This project does not publish a security email address. Do not invent one, and do not send reports to a `noreply` address — those mailboxes are not monitored.

Report vulnerabilities privately with [GitHub Security Advisories](https://github.com/ltmtms/rummi/security/advisories/new) (repository **Security** tab → **Report a vulnerability**). Please do not open a public issue for a security report.

If private vulnerability reporting is turned off, a maintainer can enable it under **Settings → Advanced Security → Private vulnerability reporting**. GitHub documents the flow in [Privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).
